# 🐍 Python Mini Projects Collection

A collection of **beginner-friendly Python projects** created to practice and strengthen fundamental programming concepts through hands-on development.

The projects cover essential Python topics such as **variables, user input, conditionals, loops, functions, strings, lists, randomization, and basic problem-solving**.

---

## 📌 About This Repository

This repository contains a set of small Python applications and games. Each project focuses on a specific programming concept while providing practical experience in building functional programs.

Whether you're just starting with Python or looking for simple projects to practice your skills, this collection provides a good foundation for further development.

---

## 📂 Projects Included

| # | Project                    | Description                                                                                          |
| - | -------------------------- | ---------------------------------------------------------------------------------------------------- |
| 1 | 🧮 **Calculator**          | Performs basic arithmetic operations such as addition, subtraction, multiplication, and division.    |
| 2 | 📝 **To-Do List App**      | A command-line application for creating and managing daily tasks.                                    |
| 3 | ✊ **Rock Paper Scissors**  | A classic interactive game where the player competes against the computer.                           |
| 4 | 🔐 **Password Generator**  | Generates random and strong passwords using different character types.                               |
| 5 | 🎯 **Hangman Game**        | A word-guessing game where players attempt to identify a hidden word before running out of attempts. |
| 6 | 🔒 **Caesar Cipher Game**  | Encrypts and decrypts messages using the Caesar Cipher technique.                                    |
| 7 | 🍕 **Pizza Order Program** | Calculates the total cost of a pizza based on the user's selected options.                           |
| 8 | ❤️ **Love Calculator**     | A fun program that calculates a compatibility score based on two names.                              |

## ⚙️ Requirements

Before running the projects, make sure you have:

* **Python 3.x**
* A code editor such as **Visual Studio Code**, PyCharm, or any preferred IDE
* Basic knowledge of running Python programs from the terminal

Check your Python installation:

```bash
python --version
```

or:

```bash
python3 --version
```

## 💡 Learning Approach

Each project is intentionally small and focused on a specific programming problem.

A recommended learning approach is:

```text
Learn Python Concept
        ↓

        ↓
Test the Program
        ↓
Identify Problems
        ↓
Improve the Code
        ↓
Build the Next Project
```

This approach helps transform theoretical Python knowledge into practical programming skills.
