## 🐍 Python Mini Projects Collection

This repository contains a set of beginner-friendly Python projects. Each project is designed to practice basic programming concepts such as conditionals, loops, functions, and user input.

## 📂 Projects Included

- ✅ **Calculator**  
  A simple calculator that performs basic arithmetic operations.

- ✅ **To-Do List App**  
  A command-line app to manage daily tasks.

- ✅ **Rock Paper Scissors**  
  A classic game played against the computer.

- ✅ **Password Generator**  
  Generates strong and random passwords.

- ✅ **Hangman Game**  
  A word guessing game with stages and hints.

- ✅ **Caesar Cipher Game**  
  Encrypt and decrypt messages using Caesar Cipher.

- ✅ **Pizza Order Program**  
  Calculates total pizza cost based on user choices.

- ✅ **Love Calculator**  
  Fun project that calculates compatibility between two names.

## 📁 Additional Files

- `hangman_stages.py` → Contains visual stages for the Hangman game  
- `word_file.py` → Stores words used in the Hangman game  

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
````

2. Navigate to the project folder:
   ```bash
   cd your-repo-name
   ```

3. Run any Python file:
   ```bash
   python filename.py
   ```
